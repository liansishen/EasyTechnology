# EasyTechnology

[English](README.md) | [简体中文](README.zh-CN.md)

EasyTechnology 是一个面向 GregTech: New Horizons 的小型附属模组，主要添加用于前中期自动化的便利物品和机器。

## 功能介绍

### 纠缠卡片

纠缠卡片可以记录一个维度和方块坐标。

- 右键方块可记录该方块的坐标。
- 右键空气可记录玩家当前所在坐标。
- 将记录后的卡片放入纠缠采矿机，即可在目标坐标附近开采矿石，包括其他维度中的目标。
- 已记录坐标的卡片会显示附魔光效。

### 纠缠采矿机

纠缠采矿机从纠缠卡片记录的位置附近开采真实存在的矿石方块。可以使用螺丝刀调整工作区域，使用软锤停止采矿。

| 采矿机 | 能源 | 最大工作范围 |
| --- | --- | --- |
| 原始纠缠采矿机 | 熔炉燃料 | 17 x 17 |
| 青铜纠缠采矿机 | 蒸汽 | 17 x 17 |
| 低压纠缠采矿机 | EU | 17 x 17 |
| 中压纠缠采矿机 | EU | 33 x 33 |
| 高压纠缠采矿机 | EU | 49 x 49 |

低压、中压和高压纠缠采矿机的工作范围与同电压等级的 GregTech 普通采矿机一致。

### 虚拟油田定位卡

站在目标区块内右键空气，可以记录该区块的维度、区块坐标、地下流体类型以及虚拟油田剩余储量。

将记录后的定位卡放入油气流体矿机的控制器物品栏，矿机将从卡片记录的区块抽取石油，包括位于其他维度的区块。已记录油田的定位卡会显示附魔光效。

### 便携合成站

便携合成站无需放置方块即可打开匠魂合成站界面。

- 手持物品右键即可打开界面。
- 可以设置快捷键；只要物品位于玩家背包中，就能通过快捷键打开。
- 支持普通合成以及匠魂工具的修复和强化。

### 治愈指环

治愈指环可以佩戴在 Baubles 指环栏中。佩戴后，每两秒恢复少量饥饿值和饱和度。

其配方使用 Extra Utilities 的治愈之斧，因此仅在安装 Extra Utilities 时注册。

### 虚拟资源钻机无需采矿管道

用于采集地下油田、虚空资源等虚拟资源的 GregTech 多方块钻机无需采矿管道即可工作。
